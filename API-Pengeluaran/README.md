# API Pengeluaran

API Backend sederhana yang dibangun menggunakan Node.js, Express.js, dan MySQL untuk mencatat transaksi pengeluaran beserta kategorinya.

---

#Prasyarat
Sebelum menjalankan proyek ini, pastikan komputer Anda telah terpasang:
- [Node.js](https://nodejs.org/) (versi LTS)
- [XAMPP](https://www.apachefriends.org/) (atau MySQL Server / Laragon)

---
